📘 Guida all'uso di postAllIn

Benvenuto! Questa guida ti spiega passo dopo passo come usare postAllIn per creare automaticamente il file allin.csv per la gestione dei tuoi tornei di scacchi.

1. Generare il file principale allin.csv

Questa è la procedura standard che userai la maggior parte delle volte.

Come si usa

  1. Vai alla pagina principale dello strumento: https://nicolopinci.github.io/postallin/.
  2. Nei riquadri a sinistra, carica i tre file obbligatori che hai scaricato dai portali ufficiali:
    • L'elenco dei tesserati FSI (es. elenco_tesserati.csv).
    • Il file Vega del mese (es. 2024_01_vega.csv).
    • La lista aggiornata dei giocatori FIDE (players_list.txt).
  3. Ignora per ora il passaggio 3 "Candidati ID FIDE" (è opzionale, ne parliamo più sotto).
  4. Clicca sul pulsante blu Elabora dati.

Cosa ottieni

Il sistema incrocia i database per te. Prende l'anagrafica dalla FSI, aggiorna l'Elo nazionale da Vega e recupera tutti i dati internazionali (Elo standard/rapid/blitz, titoli mondiali) dal file FIDE. Alla fine dell'elaborazione:

  • Potrai scaricare il file allin.csv finale e pulito, pronto per essere importato nel tuo software per gli abbinamenti.
  • Nella finestra scura a destra (il log), vedrai un riepilogo delle operazioni. Se il sistema nota delle incongruenze (ad esempio se un giocatore risulta avere un anno di nascita o un sesso diverso tra il database italiano e quello internazionale), lo segnalerà lì. Puoi salvare questi avvisi sul tuo computer cliccando su "Scarica log".

2. Trovare i candidati FIDE (strumento opzionale)

A volte ti ritrovi con giocatori italiani che non hanno l'ID internazionale registrato sul file Vega, ma magari ne hanno già uno. Questo strumento secondario ti aiuta a scovarli in automatico.

Come si usa

  1. Dalla pagina principale di postAllIn, clicca sul link in alto "Genera i possibili abbinamenti ID FSI-FIN automaticamente". Si aprirà una pagina secondaria.
  2. Carica di nuovo i tre file base (elenco FSI, Vega e lista FIDE).
  3. Clicca su Trova candidati.

Cosa ottieni

Il sistema confronterà il nome, il cognome e l'anno di nascita dei tesserati italiani "scoperti" con tutti i giocatori del mondo presenti nel database FIDE. Alla fine ti farà scaricare un file chiamato candidati.csv con le corrispondenze trovate.

Come usare il risultato

Una volta scaricato candidati.csv, torna sulla pagina principale di postAllIn. Quando vai a generare il tuo file generale, inserisci questo file appena creato nello step 3 (opzionale) prima di avviare l'elaborazione.

In questo modo, il sistema assegnerà automaticamente l'ID internazionale trovato ai giocatori. Per sicurezza e per ricordarti di verificare manualmente la correttezza dell'abbinamento, il nome di questi giocatori nel file finale avrà l'etichetta "(presunto)" aggiunta in coda.
